# Audio Assets

Place optional audio files here. MP3, OGG, and WAV are supported.

## Common

- `bgm.mp3`
- `shoot.mp3`
- `hit.mp3`
- `boss.mp3`
- `destroy.mp3`
- `ally.mp3`
- `item.mp3`
- `ultimate.mp3`

## Per Stage

Use `N` as the stage number from 1 to 5.

- `shoot_stageN.mp3`
- `hit_stageN.mp3`
- `boss_stageN.mp3`
- `destroy_stageN.mp3`
- `ally_stageN.mp3`
- `item_stageN.mp3`
- `ultimate_stageN.mp3`
