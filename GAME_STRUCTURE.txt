거북선 전쟁 슈팅게임 개발 구조 설명
작성일: 2026-05-03

1. 게임 전체 컨셉

이 게임은 pygame으로 만든 2D 세로형 슈팅게임입니다.
플레이어는 거북선을 조종하고, 위에서 내려오는 적 함선을 대포로 격침합니다.
전투는 중앙 모바일형 플레이 영역에서 진행됩니다.
좌우 여백은 전투 공간이 아니며, 현재는 왼쪽 예비 구역과 오른쪽 HUD 구역으로 사용합니다.
게임은 전체화면이 아니라 최대화된 창으로 실행됩니다.

현재 모드는 두 가지입니다.

이순신 시뮬레이션:
1단계부터 5단계까지 순서대로 잠금 해제되는 캠페인 모드입니다.
게임을 다시 켜도 campaign_progress.json에 저장된 진행도를 읽어 이어서 할 수 있습니다.
각 스테이지는 난중일기/해전 브리핑 화면을 거친 뒤 전투로 들어갑니다.
캠페인 증강은 영구 저장되지 않고 현재 스테이지 안에서만 유지됩니다.

점수 경쟁:
한 판 안에서 적을 격침해 경험치를 얻고 레벨업 증강을 고르는 점수 도전 모드입니다.
점수 경쟁 증강도 현재 판에서만 유지됩니다.
캠페인 잠금 상태와 별개로 증강/무기 진화 흐름을 빠르게 체험하는 용도입니다.

2. 화면 상태 흐름

menu:
메인 메뉴 화면입니다.
이순신 시뮬레이션 또는 점수 경쟁을 선택합니다.
Space는 선택키가 아니며 Enter 또는 마우스로 선택합니다.

stage_select:
캠페인 스테이지 선택 화면입니다.
처음에는 1단계만 열려 있습니다.
1단계를 클리어하면 2단계가 열리고, 같은 방식으로 5단계까지 열립니다.
스테이지 선택 화면용 배경음악과 디자인 이미지를 나중에 넣을 수 있습니다.

story:
난중일기/해전 기록 화면입니다.
첫 1단계 캠페인을 처음 시작하면 4월 13일, 14일, 15일 도입 난중일기가 먼저 표시됩니다.
스토리 문구에는 난중일기와 해전 기록만 넣고, 게임식 설명과 조작 설명은 넣지 않습니다.
story_diary_horizontal.png가 있으면 가로 일기지 이미지 위에 인용문과 본문이 천천히 쓰이는 애니메이션으로 나옵니다.
글이 쓰이는 중 Enter 또는 클릭을 한 번 누르면 현재 페이지 전체 문장을 즉시 표시하고, 다시 누르면 다음 페이지로 넘어갑니다.
스토리 이미지는 공통 이미지, 스테이지 이미지, 페이지 이미지, phase별 페이지 이미지 순서로 찾습니다.
스토리 BGM도 공통, 스테이지, 페이지, phase별 이름을 지원합니다.

ability_select:
1단계 첫 전투 전에만 나오는 기본 능력 선택 화면입니다.
무기 진화, 랜덤 스킬, 기본 체력 증가 중 하나를 고릅니다.
선택한 기본 능력은 1단계 사천포와 당포 전투 동안 유지됩니다.

play:
실제 전투 화면입니다.
플레이어, 일반 적, 보스, 탄환, 날씨, 파도, 지형지물, HUD가 매 프레임 갱신됩니다.
넓은 화면에서는 왼쪽 전체 영역을 story_summary_vertical.png가 여백 없이 꽉 채우고, 그 위에 현재 출전 기록 요약을 보여줍니다.
오른쪽 전체 영역에는 기존 HUD가 표시됩니다.

augment_select:
전투 중 경험치가 충분히 쌓이면 열리는 증강 선택 화면입니다.
방향키 또는 WASD로 선택지를 이동하고, Enter/숫자키/마우스 클릭으로 1개를 고르면 전투로 돌아갑니다.
증강은 현재 스테이지 또는 현재 점수 경쟁 한 판 안에서만 유지됩니다.

stage_result:
캠페인 스테이지를 클리어했을 때 나오는 결과 화면입니다.
총 점수, 격침 수, 대포 발사 수, 피격 횟수, 받은 피해, 스킬 사용량을 표시합니다.
나중에 결과 화면 전용 이미지를 넣을 수 있도록 이미지 슬롯을 만들어 두었습니다.

gameover / clear:
게임오버 또는 전체 캠페인 클리어 화면입니다.
Space가 자동 선택되지 않고 Enter 또는 클릭으로 다음 화면으로 갑니다.

3. 캠페인 진행 구조

현재 캠페인은 5개의 선택 카드로 구성됩니다.
다만 1단계는 내부적으로 2개의 전투 phase를 가집니다.

시작 흐름:
메뉴 -> 해전 선택 -> 1단계 선택 -> 4월 13일 난중일기 -> 4월 14일 난중일기 -> 4월 15일 난중일기 -> 사천포 브리핑 -> 기본 능력 선택 -> 1-1 사천포해전 -> 당포 브리핑 -> 1-2 당포해전 -> 1단계 결과 -> 2단계 해금

그 이후 흐름:
2단계 한산도해전(학익진 확정 획득) -> 결과 -> 3단계 해금
3단계 부산포해전(강한 샛바람과 파도) -> 결과 -> 4단계 해금
4단계 스토리(칠천량해전 -> 삼도수군통제사 재임명 -> 생즉사 사즉생) -> 명량해전 -> 결과 -> 5단계 해금
5단계 노량해전 -> 결과 -> 전체 클리어

1단계 내부 phase:
stage_phase = 0이면 1-1 사천포해전입니다.
stage_phase = 1이면 1-2 당포해전입니다.
stages.py의 phase_names, phase_kills_to_boss, phase_boss_hp, phase_boss_shield 값으로 조정합니다.

4. 조작 방식

이동:
WASD, 방향키, 한글 입력 상태의 같은 물리 키를 지원합니다.
input.py는 pygame key 값과 scancode를 함께 확인합니다.
그래서 한글 입력 상태에서도 W/A/S/D 위치의 물리 키로 이동할 수 있습니다.

발사:
Space 또는 마우스 왼쪽 버튼으로 발사합니다.
pygame.key.set_repeat(0)을 사용해서 Space를 꾹 누를 때 자동 연사가 되지 않게 했습니다.
발사는 키를 눌렀을 때 한 번만 나갑니다.

화면 선택:
메뉴, 스테이지 선택, 스토리, 기본 능력 선택, 증강 선택, 결과 화면에서는 Space가 선택키가 아닙니다.
기본 능력/증강/생즉사 사즉생 선택 화면은 방향키 또는 WASD로 이동하고 Enter로 선택할 수 있습니다.
숫자키와 마우스 클릭도 계속 지원합니다.

전술 스킬:
Q / ㅂ: 학익진 전술
Z / ㅋ: 몸빵 전술
X / ㅌ: 치유 전술

5. 증강 시스템

증강은 augments.py에서 관리합니다.
증강은 영구 능력치가 아닙니다.
캠페인에서는 현재 스테이지에서만 유지되고, 점수 경쟁에서는 현재 한 판에서만 유지됩니다.
새 스테이지 또는 새 점수 경쟁을 시작하면 augments.reset_run()으로 초기화됩니다.

경험치:
적을 격침하면 rewards.py가 augments.add_experience()를 호출합니다.
경험치가 충분하면 run_level이 오르고 augment_select 화면이 열립니다.
레벨이 오를수록 get_xp_to_next_level()이 더 높은 경험치 요구량을 계산합니다.

기본 능력 선택:
1단계 첫 전투 전에 BASIC_ABILITY_CHOICES 중 하나를 고릅니다.
무기 진화는 현자총통을 바로 얻습니다.
랜덤 스킬은 장전 훈련, 노군 훈련, 치유 전술 중 하나를 줍니다.
기본 체력 증가는 선체 보강을 줍니다.

무기 진화:
0단계 황자총통: 기본 1발 포격입니다.
1단계 현자총통: 일자 포격 피해가 증가합니다.
2단계 지자총통: 3발 광역 포격을 발사합니다.
3단계 천자총통: 5발 광역 포격을 발사합니다.
무기 단계별 피해/크기는 combat.py의 get_player_weapon_stats()에서 조정합니다.
발사 패턴은 combat.py의 get_player_weapon_pattern()에서 조정합니다.

학익진 규칙:
캠페인 1단계에서는 학익진 증강이 나오지 않습니다.
캠페인 2단계부터는 stage 시작 시 학익진 전술을 확정으로 얻습니다.
점수 경쟁에서는 단계 제한 없이 학익진 증강이 후보에 나올 수 있습니다.

6. 스킬 시스템

skills.py가 전술 스킬을 관리합니다.
스킬은 보통 해금 여부, 쿨타임, 지속시간을 확인한 뒤 발동합니다.

학익진:
Q/ㅂ로 사용합니다.
학익진 전술이 해금되어야 쓸 수 있습니다.
12척의 전술선이 학익진 형태로 나타납니다.
전술선은 자동으로 가장 가까운 적이나 보스를 향해 강한 포격을 합니다.
학익진은 현재 궁극기 느낌에 가깝게 화력과 사격 빈도를 높였습니다.

몸빵:
Z/ㅋ로 사용합니다.
플레이어 앞에 방패선이 나타나 적 탄환과 적 배를 막습니다.

치유:
X/ㅌ로 사용합니다.
지속시간 동안 체력을 회복합니다.

생즉사 사즉생:
4단계 명량해전 직전에 한 번 선택하는 생존 이벤트입니다.
죽고자 하면 살 것이다: 체력이 10% 이하일 때 한 번 발동합니다.
이 선택지는 체력을 10% 수준으로 유지하고, 짧은 무적 시간과 8초 공격력 10배 버프를 줍니다.
살고자 하면 죽는다: 체력이 0이 되었을 때 한 번 판정합니다.
이 선택지는 낮은 확률로 체력을 일부 회복하고 부활합니다.
두 선택지는 모두 현재 명량해전 한 판에서만 유지됩니다.

4단계 고립 전투:
명량해전은 스테이지 시작 후 30초 동안 stage_handicap_timer가 켜집니다.
이 시간에는 Q/Z/X 전술 스킬을 사용할 수 없습니다.
HUD에는 남은 고립 시간이 표시됩니다.

7. 파도 시스템

waves.py가 파도 방향과 속도를 관리합니다.
기본 파도 방향은 BASE_WAVE_ANGLE = -pi/2입니다.
pygame 좌표계에서 -pi/2는 위쪽이므로, 기본 흐름은 아래에서 위로 향합니다.

파도 방향은 18~30초 사이의 랜덤 간격으로 목표 방향을 바꿉니다.
현재 방향은 목표 방향으로 천천히 회전합니다.
이전보다 방향 전환을 덜 자주 하게 해서 플레이 피로도를 줄였습니다.

순풍/역풍:
플레이어가 파도 방향으로 이동하면 이동속도가 조금 증가합니다.
플레이어가 파도 반대 방향으로 이동하면 이동속도가 감소합니다.
파도와 수직에 가까우면 속도 변화가 작습니다.

화면 파도와 실제 이동 방향:
render.py의 draw_wave_overlay()와 actors.py의 이동 보정은 모두 waves.get_wave_state()의 unit_x, unit_y를 사용합니다.
그래서 화면에 보이는 파도 방향과 실제 밀리는 방향은 같은 기준입니다.

8. 날씨 시스템

weather.py가 날씨를 관리합니다.
날씨는 10~15초 사이의 랜덤 간격으로 등장할 기회를 얻습니다.
한 번에 최대 1개 날씨 이벤트만 유지됩니다.
사라지기 1초 전부터 깜빡입니다.

태풍:
랜덤 위치에 영역형으로 나타납니다.
태풍 영역 안에 있는 플레이어, 적, 보스는 지속 피해를 받습니다.
태풍이 떠 있는 동안에는 태풍 안에서만이 아니라 전체 플레이 영역의 파도 영향이 강해집니다.

비:
전체 플레이 영역에 적용됩니다.
플레이어, 적, 보스 이동속도를 늦춥니다.

번개:
전체 플레이 영역 이벤트입니다.
플레이어, 적, 보스 중 랜덤 1명을 1초 동안 이동 마비시킵니다.
스킬과 발사는 막지 않습니다.
번개가 등장할 때 weather_lightning 효과음을 재생합니다.

9. 지형지물 시스템

obstacles.py가 지형지물을 관리합니다.
지형지물은 랜덤 위치에 생겼다가 랜덤 지속시간 뒤 사라집니다.
플레이어는 통과할 수 없습니다.
플레이어 탄환과 적 탄환도 지형지물을 관통하지 못합니다.
사라지기 1초 전부터 깜빡입니다.
이미지나 크기, 지속시간은 obstacles.py에서 쉽게 바꿀 수 있습니다.

10. 스테이지별 현재 구현

1단계 사천포·당포해전:
1-1 사천포해전과 1-2 당포해전으로 나뉩니다.
일반 적은 소형 왜선 위주이며, 약한 화살 공격을 천천히 발사합니다.
사천포는 10척 격침 후 도쿠이 미치유키 지휘선이 등장합니다.
당포는 14척 격침 후 가메이 고레노리 대장선이 등장합니다.
당포까지 클리어해야 1단계 결과 화면이 나오고 2단계가 해금됩니다.

2단계 한산도해전:
적은 기동성이 높고 약한 직선 탄환을 발사합니다.
캠페인에서는 학익진 전술을 확정으로 얻습니다.
보스는 확산 탄막 패턴을 사용합니다.

3단계 부산포해전:
470여 척 규모의 함대 압박을 축약해 중형 왜선과 총포 중심으로 구현했습니다.
강한 파도와 바람 느낌을 주기 위해 플레이어 기본 속도에 스테이지 보정을 적용합니다.
보스는 fan 패턴을 사용하고, 탄환 분열로 압박합니다.

4단계 명량해전:
칠천량해전 스토리 이후 체력 절반 상태로 시작합니다.
초반 30초는 고립 전투입니다.
고립 시간 동안 전술 스킬이 막힙니다.
출전 직전에 생즉사 사즉생 선택지를 고릅니다.
보스는 도도 다카토라 전함이며 저격형 직선 탄막 느낌입니다.

5단계 노량해전:
새벽의 어두운 바다를 표현하기 위해 플레이 영역 배경을 어둡게 덮습니다.
자폭선과 대형 적선이 함께 나옵니다.
자폭선은 붉은 테두리로 표시되고, 플레이어와 충돌하면 큰 피해를 줍니다.
최종 보스는 보호막을 재생하고 storm 패턴을 사용합니다.

11. 오디오 안정화

assets.py에서 pygame.mixer 채널 수를 64개로 늘렸습니다.
대포, 피격, 격침, 번개, 보스, 스킬, 필살기 효과음은 전용 채널 묶음을 사용합니다.
대포 발사음은 여러 채널을 돌려 쓰므로 빠르게 쏴도 소리가 빠질 가능성을 줄였습니다.
모든 전용 채널이 바쁘면 첫 번째 전용 채널을 강제로 사용해 최신 효과음이 완전히 빠지지 않게 했습니다.

13. 파일별 역할

main.py:
pygame을 초기화하고, 최대화 창을 만들고, 게임 루프를 실행합니다.
updateGame()에서 전투 중 매 프레임 어떤 순서로 기능이 갱신되는지 볼 수 있습니다.

input.py:
키보드와 마우스 입력을 처리합니다.
화면 상태별로 같은 키가 다른 역할을 할 수 있으므로, game.game_state를 보고 분기합니다.

campaign.py:
스테이지 잠금/해금과 진행도 저장을 담당합니다.
campaign_progress.json을 읽고 씁니다.

story.py:
난중일기, 브리핑, 해금 문구, 스토리 페이지 데이터를 관리합니다.
1단계 phase별 스토리도 이 파일에서 관리합니다.

stages.py:
스테이지 공통 정보와 phase별 보스/목표 격침 수를 관리합니다.
ENEMY_STAGES와 BOSS_STAGES를 합쳐 최종 STAGES 리스트를 만듭니다.

enemies.py:
일반 적의 체력, 속도, 등장 간격, 크기, 일반 적 탄환, 자폭선 확률을 관리합니다.

bosses.py:
미니보스 이름, 특징, 체력, 보호막, 패턴, 접촉 피해를 관리합니다.

actors.py:
플레이어, 일반 적, 보스를 만들고 이동시킵니다.
스테이지 시작, phase 전환, 결과 화면 이동 같은 큰 전투 흐름도 담당합니다.

combat.py:
플레이어 발사, 탄환 충돌, 적/보스 피해, 플레이어 피해를 처리합니다.
무기 단계별 포격 수치와 패턴도 이 파일에서 계산합니다.

projectiles.py:
플레이어 탄환, 적 탄환, 보스 탄환을 데이터로 만들고 이동시킵니다.
분열탄 로직도 이 파일에 있습니다.

augments.py:
현재 판 전용 경험치, 레벨업, 증강 후보, 기본 능력 선택, 증강 효과를 관리합니다.
새 증강을 추가할 때 가장 많이 수정할 파일입니다.

skills.py:
학익진, 몸빵, 치유, 생즉사 사즉생, 필살기 관련 타이머와 발동 조건을 관리합니다.

waves.py:
파도 방향, 파도 속도, 파도에 밀리는 이동, 순풍/역풍 이동속도 보정을 담당합니다.

weather.py:
태풍, 비, 번개를 생성하고 효과를 적용합니다.
날씨 투명도, 지속시간, 등장 확률도 여기서 수정합니다.

obstacles.py:
랜덤 지형지물을 생성하고, 플레이어와 탄환이 통과하지 못하게 막습니다.

rewards.py:
적 격침과 보스 격파 후 보상 흐름을 연결합니다.
현재는 경험치와 필살기 충전을 연결합니다.

results.py:
전투 기록을 모아 결과 화면용 딕셔너리를 만듭니다.
점수, 격침 수, 피격 횟수, 받은 피해, 스킬 사용량을 관리합니다.

assets.py:
이미지와 효과음을 불러오고, 스테이지별 이미지/사운드를 찾아 돌려줍니다.
BGM 재생과 효과음 전용 채널도 담당합니다.

skins.py:
플레이어 표시 크기, 히트박스 크기, 배경 플레이 영역, 에셋 이름 목록을 정의합니다.
새 이미지 슬롯을 만들 때 먼저 확인할 파일입니다.

layout.py:
화면 크기에 맞춰 플레이 영역, 전투 영역, 좌우 HUD 영역, 버튼 위치를 계산합니다.

ui.py:
메뉴, 스테이지 선택, 스토리, 기본 능력 선택, 증강 선택, HUD, 결과 화면을 그립니다.

render.py:
전투 화면의 실제 오브젝트를 그립니다.
배경, 파도, 지형지물, 탄환, 적, 보스, 전술선, 플레이어, 날씨, HUD 순서로 그립니다.

14. 기능을 추가할 때 보는 위치

새 증강 추가:
augments.py의 AUGMENTS에 항목을 추가합니다.
apply_augment_effect()에 실제 효과를 연결합니다.

새 스킬 추가:
skills.py에 키 판정 함수, try_use 함수, update 함수 처리를 추가합니다.
ui.py의 HUD에 쿨타임/지속시간 표시를 추가합니다.

스테이지 밸런스 조정:
stages.py, enemies.py, bosses.py의 숫자만 먼저 조정합니다.
로직 자체는 actors.py와 combat.py가 읽어 사용합니다.

새 스토리 추가:
story.py에서 STAGE_STORIES에 pages 리스트를 추가합니다.
스토리 이미지가 필요하면 story_stageN_pageM.png 또는 story_stageN_phaseP_pageM.png를 넣습니다.

새 BGM 추가:
assets/audio/에 story_stageN_bgm.mp3, story_stageN_pageM_bgm.mp3, story_stageN_phaseP_bgm.mp3 같은 이름으로 넣습니다.

파도 조정:
waves.py의 WAVE_CHANGE_INTERVAL_RANGE, WAVE_WITH_SPEED_BONUS, WAVE_AGAINST_SPEED_PENALTY를 조정합니다.

날씨 조정:
weather.py의 WEATHER_TYPES에서 weight, duration_range, alpha, damage_per_second, speed_multiplier를 조정합니다.

지형지물 조정:
obstacles.py에서 등장 간격, 지속시간, 깜빡임 시간, 크기를 조정합니다.

결과 화면 UI 교체:
assets/images/stage_result_background.png와 stage_result_panel.png를 넣습니다.
스테이지별로 다르게 만들고 싶으면 stage_result_stageN.png를 넣습니다.
